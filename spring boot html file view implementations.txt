SpringBoot View Concept from MVC:
=================================

step 1:
	install thymeleaf (purpose --> implement .html file)

	pom.xml:  (project object model ---> use --> maintain dependencies)
	========

	<dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-thymeleaf</artifactId>
        </dependency>


	ctrl+s (save) --->it will install automattically

step 2:
	add html file:
	==============
	src.main.resources -------> templates folder -----> right click
	---> new ---> html file

	file name: index.html

html file shold be this format:
===============================
<!DOCTYPE html>
<html xmlns:th="https://www.thymeleaf.org">
<head>
<meta charset="UTF-8">
<title>Insert title here</title>
</head>
<body>
<h1 th:text=${name}></h1>
<h1>Welcome To View in MVC</h1>
</body>
</html>
step 3:
=======
	controller:src/main/java

	com.gowthamspring.demoproject------>right click---> class--> PeopleController

example:
	
package com.gowthamanspring.demoproject;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;

@Controller
public class PeopleController {

	@GetMapping("/")
	public String getPeople(Model model)
	{
		model.addAttribute("name","gowthaman");
		return "index";
	}
}

note: index --->template folder -->index.html file

demoprojectapplication.java-->right click-->run as-->java application

browser open-->http://localhost:8080/ 
browser open-->http://localhost:8080/index.html
